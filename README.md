# RestoCanvas — Система бронирования и управления залом

Система управления рестораном: схема залов, бронирования, задачи, отчёты.

## Запуск

```bash
# Установить зависимости
npm install

# Собрать проект
npm run next:build

# Запустить сервер (доступен по сети для телефонов)
npm run start:lan
```

Или просто запустить `START_RESTAURANT.bat` (Windows).

Приложение будет доступно по адресу: `http://localhost:3000/restaurant`

## Стек

- **Next.js 16** (App Router)
- **React** (TypeScript)
- **Vanilla CSS**
- Локальное хранилище в файле `.data/restaurant-state.json`
